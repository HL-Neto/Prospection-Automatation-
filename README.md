🔎 Prospection Automatation

Automação de prospecção de empresas utilizando Google Maps API, DuckDuckGo e Inteligência Artificial.

O sistema busca estabelecimentos em uma determinada região e verifica quais possuem um site próprio.

⚙️ Tecnologias
Python
Google Maps / Places API
DuckDuckGo
Google Gemini
LangChain
🚀 Fluxo
Google Maps
     ↓
Empresas
     ↓
Verificação de site
     ↓
DuckDuckGo + IA
     ↓
COM SITE / SEM SITE

Os resultados são separados nos arquivos:

COM SITE.txt
SEM SITE.txt
